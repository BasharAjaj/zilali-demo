# ظلالي — ديمو موقع مظلات وسواتر + لوحة تحكم

ديمو تجريبي لإقناع العميل: موقع فاخر متجاوب + حاسبة سعر + لوحة تحكم. **كل البيانات والأسعار افتراضية للعرض.**

## التشغيل محلياً
```bash
python tools/serve.py 8080
# ثم افتح http://127.0.0.1:8080/
```
أو افتح `index.html` مباشرة في المتصفح (الروابط نسبية).

- الموقع: `index.html`
- لوحة التحكم: `admin/index.html`

## النشر على GitHub Pages (الطريقة الموصى بها)
1. أنشئ مستودعاً على GitHub وارفع كل ملفات هذا المجلد.
2. Settings ← Pages ← Source: `main` / `/ (root)` ← Save.
3. الرابط يصبح `https://<user>.github.io/<repo>/`.

على GitHub Pages تعمل **المزامنة الحية**: عدّل سعراً في لوحة التحكم (`/admin/`)، افتح الحاسبة (`/pricing/`)، وسيتغيّر السعر — لأن الصفحتين على نفس النطاق وتتشاركان تخزين المتصفح.

## نسخة الملف الواحد (لمشاركة رابط فوري)
```bash
node tools/bundle.mjs   # ينتج dist/index.html و dist/admin.html
```
كل CSS و JS مدمج داخل كل ملف. مناسبة للنشر كصفحة واحدة (Artifact/أي استضافة).
**قيد:** رابطا الملف الواحد المنفصلان لا يتشاركان التخزين (نطاقان مختلفان)، فالمزامنة الحية بينهما لا تعمل — استخدم GitHub Pages لعرض المزامنة.

## توليد الصفحات والملفات
```bash
node tools/generate.mjs      # يبني صفحات الخدمات/المقالات/المشاريع/الفهارس من البيانات
node tools/gen-sitemap.mjs   # sitemap.xml
node tools/check-seo.mjs     # فحص السيو لكل صفحة
```

## البيانات
كل البيانات في `assets/js/seed.js` (القيم الأولية) وتُحفظ التعديلات في `localStorage` تحت المفتاح `zilali:v1`.

> ⚠️ **مهم:** `localStorage` ليس باك إند. طلبات التسعير التي يحفظها الزائر تبقى **في متصفحه فقط** ولا تصل الشركة. هذه المزامنة كافية للديمو، لكن المنتج الحقيقي يحتاج خادماً وقاعدة بيانات.

## كيف تستبدل بمحتوى العميل
1. **المدينة والأرقام والجوال:** لوحة التحكم ← الإعدادات (أو `seed.js`).
2. **الأسعار:** لوحة التحكم ← الأسعار (أو `seed.js` → `pricing`).
3. **الصور:** استبدل الأغلفة التوضيحية (SVG) بصور مشاريع العميل الحقيقية — وهي أقوى ورقة سيو.
4. **الشعار:** رمز SVG في `assets/partials.js` (دالة `brandMark`).
5. بعد أي تعديل في `seed.js`: `node tools/generate.mjs` لإعادة توليد الصفحات الثابتة.

## نحو المنتج النهائي
بعد موافقة العميل، يُعاد بناء المنتج على **Laravel + Filament** (لوحة تحكم حقيقية) مع قاعدة بيانات وتخزين صور، مع الحفاظ على نفس التصميم والبنية والسيو.
